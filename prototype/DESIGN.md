# Design System Documentation

## Theme: Dark Harmony

This design theme, "Dark Harmony," focuses on a sleek and modern aesthetic, utilizing a dark color mode with a vibrant primary accent. The typography is consistent across the UI, promoting a unified visual experience.

---

### **Color Palette**

The color palette is built around a dark mode with striking accents to ensure readability and engagement.

*   **Primary Color:** `#000eff` - A vibrant electric blue, perfect for interactive elements like buttons, links, and key calls to action. It stands out prominently against the dark backdrop.
*   **Secondary Color:** `#121417` - A very dark, almost black, background color providing depth and contrast. Used for less prominent UI elements, subtle dividers, and secondary actions.
*   **Tertiary Color:** `#38BDF8` - A bright sky blue accent, used for highlights, badges, or decorative elements, providing an additional layer of visual interest.
*   **Neutral Color:** `#0A0B0D` - A slightly lighter shade of dark grey, used for backgrounds, surfaces, and non-chromatic elements, offering a harmonious base for the UI.

The `color_mode` is set to `dark`, which informs the overall luminosity and contrast of the interface.

---

### **Typography**

The design employs a single, modern sans-serif font family across all text elements to maintain consistency and a clean aesthetic.

*   **Headline Font:** `Space Grotesk` - Used for all major headings and titles, providing a distinct and impactful presence.
*   **Body Font:** `Space Grotesk` - Applied to all paragraph text, ensuring readability and a consistent brand voice.
*   **Label Font:** `Space Grotesk` - Utilized for form labels, small text, and UI annotations, maintaining uniformity across interactive components.

---

### **Shape and Form**

The system embraces a subtly rounded aesthetic for UI elements.

*   **Roundedness:** `1` (Subtle roundedness) - Corners of UI elements feature a slight curve, softening the overall appearance without losing a sense of modernity. This value promotes a refined, approachable feel.

---

### **Layout and Spacing**

The layout prioritizes a spacious and open feel, allowing content to breathe and improving visual hierarchy.

*   **Spacing:** `2` (Normal) - A balanced approach to whitespace, providing comfortable padding within and between UI elements. This ensures a clean, uncluttered interface that is easy to navigate and digest.
